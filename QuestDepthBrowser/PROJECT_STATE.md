# Quest Depth Browser - Project State

## Current baseline

Version: **0.1.0 prototype**
Branch: `depth-browser-prototype`
Target: Quest 3 / Quest 3S

## Definition of success

A conventional 2D web page rendered by Android WebView is shown on a spatial panel in passthrough and is automatically occluded by closer real-world geometry from Environment Depth.

## Implemented

- Chromium-based Android WebView
- Spatial SDK 0.14.0 baseline
- Passthrough on startup
- Environment Depth automatic occlusion
- Mesh-rendered UI panel
- Grabbable browser window
- URL field and basic navigation
- Runtime Depth ON/OFF comparison button
- GitHub Actions APK build

## Deferred

- Tabs
- Downloads and upload chooser
- Bookmarks/history
- Password/autofill integration
- Layer-rendered panel experiment
- Soft/custom depth edge filtering
- Window resize handles
- Multiple windows

Quest Depth Browser Native v0.2.2

Expected behavior:
- Passthrough room visible.
- Browser image remains compositor-sharp.
- Environment Depth still occludes the browser behind real objects.
- The browser VirtualDisplay now uses a fullscreen/no-title display-aware Presentation to avoid cropping and density mismatches.
- Initial panel width is 1.00 m; height follows the actual browser texture aspect ratio.

Controls:
- Right controller aim: point at the browser.
- Right Trigger: click/tap inside Chromium.
- Right Grip: grab and move the browser panel.
- Right Grip + Trigger: resize mode. Move the controller up to enlarge and down to shrink.
- Right Grip + right thumbstick up/down: secondary resize fallback.
- Address bar: click, then type with a physical keyboard.
- DE-QWERTZ remap remains enabled for the MX Keys path, including Y/Z and common German special characters.

The sharp per-eye compositor quads and Environment Depth alpha-mask render path are unchanged from v0.2.0/v0.2.1.

Quest Depth Browser Native v0.2.5

Expected behavior:
- Passthrough room visible.
- Browser remains compositor-sharp.
- Environment Depth still occludes the browser behind real objects.
- The GPU producer surface stays fixed for the full app lifetime.
- Spatial aspect changes resize only a centered Android/WebView viewport inside that fixed producer.
- The native shader samples exactly that centered viewport, so the page and toolbar should no longer be clipped or stuck to the right edge.
- Chromium receives an explicit resize event after the viewport relayout.
- Sticky Quest-style URL/navigation bar and DE-QWERTZ remain enabled.
- Native OpenXR border/corner marker remains enabled for geometry diagnostics.

Controls:
- Right controller aim: point at the browser.
- Right Trigger: click/tap inside Chromium.
- Right Grip on browser body: grab and move the whole window.
- Right Grip on a corner: drag that corner to resize width and height independently; opposite corner remains anchored.
- Address bar: click, then type with the physical keyboard.
- DE-QWERTZ remap remains enabled for the MX Keys path.
- ^ collapses the sticky URL/navigation bar; the small down-chevron restores it.

v0.2.5 geometry checkpoint:
- GO and ^ should remain visible at the right side of the toolbar.
- Centered web content/dialogs should remain centered while changing the spatial-window aspect.
- Resizing must not change the underlying SurfaceTexture / VirtualDisplay buffer size.
- Sharp per-eye compositor quads + Environment Depth alpha-mask core are unchanged.

Quest3 MR Model Viewer v0.3.8 - Trigger UI + GLB Return Fix

UI INTERACTION
- Point at a control with the controller pointer.
- Proximity/hover alone never activates a control anymore.
- Buttons activate on a trigger click.
- Sliders move only while the trigger is held; drag and release to set the value.

PIN MOVE
- Point at PIN MOVE and click the trigger to enter MOVE mode.
- Controller 0 moves the tablet position while MOVE is active.
- Click PIN MOVE again to pin the tablet in room space.

IMPORT GLB
- Point at IMPORT GLB and click the trigger.
- Android's document picker opens.
- After selection or cancellation the viewer is explicitly brought back to the foreground.
- Imported files are validated transactionally before replacing the current mesh.
- Current guard: 192 MiB, 3,000,000 vertices, 12,000,000 indices.

MODEL
- PBR FULL toggles Normal + Metallic/Roughness processing.
- MODEL MOVE toggles controller-driven model placement.
- SCALE is adjusted by holding trigger and dragging the slider.
- ROTATE is adjusted by holding trigger and dragging the slider.
- RESET ALL restores lighting and model transform defaults.

LIGHTING
- AMBIENT
- KEY LIGHT
- AZIMUTH
- ELEVATION
- WARMTH
- EXPOSURE

The colourful Meta sample/controller cubes remain removed.
Environment Depth soft occlusion and MSAA quality pass remain enabled.

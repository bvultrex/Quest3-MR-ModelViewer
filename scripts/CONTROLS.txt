Quest3 MR Model Viewer v1.0.0

UI
- Either controller can point at the tablet.
- Trigger click activates buttons.
- Hold trigger and drag to adjust sliders.
- Hover/proximity alone never activates a control.

TABLET GRAB
- Bring either controller close to the tablet.
- Hold Grip/Squeeze to grab it.
- Position and full orientation follow the controller without snapping.
- Release Grip to leave the tablet in room space.
- The other hand remains available for UI interaction.

IMPORT GLB
- Trigger-click IMPORT GLB.
- Android's document picker opens in front of the XR app.
- Select a .glb file; the viewer returns automatically.
- Status text: IDLE / WAIT / READY / ERROR.
- Persisted GLBs are ignored on cold start and never auto-loaded.
- Current guards: 192 MiB file, 3M vertices, 12M indices, 2M triangles,
  4096px texture edge, 160 MiB texture residency, 256 MiB GPU estimate,
  384 MiB CPU import estimate.

MODEL
- Bring either controller close to the model and hold Grip/Squeeze to grab it.
- Full position + orientation follow the hand without snapping.
- Release Grip to leave the model in room space.
- PBR FULL enables authored Normal + Metallic/Roughness processing.
- REAL SCALE toggles physical 1:1 glTF scale: 1 linear glTF unit = 1 metre.
- SCALE adjusts fitted display scale and automatically exits REAL SCALE.
- ROTATE adjusts model yaw.
- RESET ALL restores lighting and model transform defaults.

LIGHTING
- AMBIENT
- KEY LIGHT
- AZIMUTH
- ELEVATION
- WARMTH
- EXPOSURE

Environment Depth soft occlusion remains enabled.
The colourful Meta sample/controller cubes remain removed.

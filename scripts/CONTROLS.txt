Quest3 MR Model Viewer v1.5.1 candidate

UI
- Either controller points at the tablet.
- Trigger clicks buttons; hold Trigger and drag sliders.
- Grip/Squeeze near the tablet grabs it with no snap.

IMPORT / SCENE
- IMPORT GLB loads another model without intentionally replacing older scene models.
- Up to 6 models are allowed in the current v1.5 scene.
- Combined estimated scene GPU budget: 768 MiB.
- A cold start never auto-loads an old persisted GLB.

MODELS
- Grip/Squeeze near a model to grab it. The grabbed model becomes selected.
- SIZE / SCALE / ROTATE / RESET act on the selected model.
- REMOVE MODEL deletes only the selected model and frees its GPU resources.
- Other loaded scene models remain in place after REMOVE MODEL.
- SIZE presets: FIT / 32MM / 75MM / 150MM / 300MM.
- The newest imported model is the live rig / animation target.
- Older rigged models keep a frozen pose snapshot after another model is imported.

RIG / ANIMATION
- BONES toggles the rig overlay for the current live rig.
- Joint handles support direct posing; supported hand/foot endpoints use two-bone IK.
- PLAY toggles the first supported GLB animation clip on the newest model.

IMPORT GUARDS
- 192 MiB GLB
- 3M vertices / 12M indices / 2M triangles
- 4096px texture edge
- 500 MiB mipmapped texture estimate
- 640 MiB per-model estimated GPU resources
- 384 MiB CPU import estimate

Environment Depth soft occlusion remains enabled.
